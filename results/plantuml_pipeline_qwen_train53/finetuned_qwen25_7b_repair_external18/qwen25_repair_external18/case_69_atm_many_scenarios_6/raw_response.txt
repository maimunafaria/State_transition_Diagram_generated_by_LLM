title ATM Control - Polished Requirement Specification

[*] --> Idle

state Idle
state WaitingForPIN
state ValidatingPIN
state WaitingForChoice
state Confiscating
state Ejecting

Idle --> WaitingForPIN : Card Inserted / Get PIN

WaitingForPIN --> ValidatingPIN : PIN Entered / Validate PIN
ValidatingPIN --> InvalidPIN : Incorrect PIN / Invalid PIN Prompt
ValidatingPIN --> ValidPIN : Correct PIN / Display Options

InvalidPIN --> Confiscating : Too Many Incorrect Pins / Keep Card
Confiscating --> Ejecting : Card Confiscated / Return Card

ValidPIN --> WaitingForChoice : Correct PIN / Show Options

WaitingForChoice --> TransferOption : Choose Transfer / Process Transfer
WaitingForChoice --> QueryOption : Choose Query / Process Query
WaitingForChoice --> WithdrawOption : Choose Withdrawal / Process Withdrawal

TransferOption --> ProcessingTransaction : Approved Transfer / Print Receipt, Dispense Cash, Return Card
ProcessingTransaction --> Ejecting : Transaction Complete / Return Card

QueryOption --> ProcessingTransaction : Approved Query / Print Receipt, Return Card

WithdrawOption --> ProcessingTransaction : Approved Withdrawal / Print Receipt, Dispense Cash, Return Card

ProcessingTransaction --> RejectedOperation : Rejected Request / Cancel Operation, Return Card

RejectedOperation --> Ejecting : Operation Rejected / Return Card

Ejecting --> Idle : Card Ejected / Reset System

state "System Out of Cash" as SystemOutOfCash
SystemOutOfCash --> Idle : No Cash / Display Low Cash Message

state "Resetting" as Resetting
Resetting --> Idle : Session Ended / Reset System

Idle --> [*] : End of Session / Reset System

@enduml
