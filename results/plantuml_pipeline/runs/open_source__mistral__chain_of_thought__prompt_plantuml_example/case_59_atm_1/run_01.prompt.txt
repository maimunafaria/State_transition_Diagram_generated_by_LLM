2. AmountSelection - The user selects or enters a withdrawal amount.
3. PredefinedAmountSelection - A sub-state of AmountSelection, where the user chooses from predefined amounts.
4. CustomAmountInput - A sub-state of AmountSelection, where the user inputs their own custom withdrawal amount.
5. Cancellation - The user decides to cancel the transaction.
6. TransactionCompletion - The transaction is completed successfully (card returned and receipt printed).
7. ErrorState - The state for handling errors or invalid inputs.

Initial state: Idle

Final states: TransactionCompletion, ErrorState

Events or conditions:
1. UserInputAmountEvent - Triggered when the user selects a predefined amount or inputs their own custom amount.
2. CancelTransactionEvent - Triggered when the user decides to cancel the transaction.
3. InvalidInputEvent - Triggered when an invalid input is detected (e.g., incorrect PIN, insufficient balance).

Transitions:
1. From Idle to AmountSelection upon UserInputAmountEvent.
2. From AmountSelection to PredefinedAmountSelection upon selection of a predefined amount.
3. From AmountSelection to CustomAmountInput upon user input of a custom amount.
4. From AmountSelection to ErrorState upon InvalidInputEvent.
5. From AmountSelection to Cancellation upon CancelTransactionEvent.
6. From Cancellation to TransactionCompletion upon system confirmation and card return.
7. From any state except Idle, CustomAmountInput, and ErrorState to ErrorState upon InvalidInputEvent.

Missing or ambiguous details:

2. It is unclear how the system handles the situation when the user selects an amount greater than the available balance.
3. The requirement does not mention any state for handling errors related to card insertion, PIN entry, or receipt printing. These details should be clarified in further analysis.

@startuml
title Telephone State Machine

[*] --> Idle

Idle --> Active : lift receiver / get dial tone
Active --> Idle : caller hangs up / disconnect

state Active {

    [*] --> DialTone

    state DialTone
    DialTone : do / play dial tone

    DialTone --> Dialing : dial digit(n)
    DialTone --> TimeOut : after (15 sec.)

    state Dialing

    Dialing --> Dialing : dial digit(n) [incomplete]
    Dialing --> Connecting : dial digit(n) [valid] / connect
    Dialing --> Invalid : dial digit(n) [invalid]
    Dialing --> TimeOut : after (15 sec.)

    state Invalid
    Invalid : do / play message

    state TimeOut
    TimeOut : do / play message

    state Connecting
    Connecting --> Busy : busy
    Connecting --> Ringing : connected

    state Busy
    Busy : do / play busy tone

    state Ringing
    Ringing : do / play ringing tone

    Ringing --> Talking : callee answers / enable speech

    state Talking
    Talking --> Pinned : callee hangs up
    Talking --> Pinned : callee answers

    state Pinned

}

Active --> [*] : terminate
Active --> [*] : abort

@enduml
