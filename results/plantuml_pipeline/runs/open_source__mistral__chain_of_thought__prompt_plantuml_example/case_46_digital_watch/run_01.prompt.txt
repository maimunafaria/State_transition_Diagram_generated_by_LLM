Digital Watch — Polished Requirement Specification

1. The system shall allow the user to view and adjust the time.

3. The system shall allow the user to increase values while adjusting time settings.
4. The system shall provide an alarm feature that can be turned on or off by the user.
5. The system shall support when the set alarm time matches the current time, the system shall trigger the alarm to ring.
6. The system shall allow the user to stop the alarm by pressing a specific button.

1. TimeViewingState: Displaying current time, allowing adjustment of hour, minutes, and enabling switching between settings.
2. AlarmSettingState: Allowing user to set alarm hour and minutes.
3. AlarmOnState: Alarm is turned on and ringing when the set alarm time matches the current time.
4. AlarmOffState: Alarm is turned off.
5. LightOnState: The light feature is turned on.
6. LightOffState: The light feature is turned off.

Initial state: TimeViewingState (initial state upon power-up or button press)

Final states: TimeViewingState, AlarmSettingState, AlarmOnState, AlarmOffState, LightOnState, LightOffState

Events or conditions:
1. TimeAdjustmentEvent: Triggered when the user adjusts time settings (hour, minutes).
2. SettingSwitchEvent: Triggered when the user switches between time settings and alarm settings.
3. AlarmToggleEvent: Triggered when the user turns the alarm on or off.
4. AlarmMatchEvent: Triggered when the set alarm time matches the current time.
5. AlarmStopEvent: Triggered when the user stops the alarm.
6. LightOnEvent: Triggered when the user presses the light button to turn on the light.
7. LightOffEvent: Triggered when the user releases the light button to turn off the light.

Transitions:
1. From TimeViewingState to AlarmSettingState upon SettingSwitchEvent.
2. From AlarmSettingState to TimeViewingState upon any event other than SettingSwitchEvent or AlarmToggleEvent.
3. From TimeViewingState to AlarmOnState upon AlarmMatchEvent while the alarm is turned on.
4. From AlarmOnState to AlarmOffState upon AlarmStopEvent or when the set alarm time no longer matches the current time.
5. From AlarmOffState to AlarmOnState upon AlarmToggleEvent.
6. From TimeViewingState to LightOnState upon LightOnEvent.
7. From LightOnState to LightOffState upon LightOffEvent.
