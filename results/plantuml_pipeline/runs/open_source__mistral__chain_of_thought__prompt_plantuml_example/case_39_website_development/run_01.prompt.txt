3. Career Opportunities Page (with sub-states: Updates and Application Form)

Final states: Submitted Job Application

Events or conditions:
1. User selects a project from the navigation bar (Project Selected event)
2. User chooses to view photos or videos of a project (Photo View/Video View Selection event)
3. User selects career opportunities from the navigation bar (Career Opportunities Selected event)
4. User chooses to view updates or open an application form for employment or internship (Updates/Application Form Selection event)
5. User submits a job application (Job Application Submitted event)

Transitions:
1. From Homepage to Project Page upon Project Selected event

8. From any state to Submitted Job Application state upon Job Application Submitted event
9. From Submitted Job Application state, no valid transitions as it is a final state

Missing or ambiguous details:
