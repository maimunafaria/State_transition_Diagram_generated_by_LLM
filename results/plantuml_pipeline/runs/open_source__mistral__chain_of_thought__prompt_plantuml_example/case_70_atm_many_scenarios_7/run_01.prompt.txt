4. The system shall keep the card for security if it is invalid or the PIN is entered incorrectly too many times.
5. The system shall return the card if the user cancels the operation.

1. Arrival State: This state represents when the user arrives at the ATM and the system greets them.
2. PIN Input State: This state starts once the card is inserted, and the user enters their PIN.
3. Incorrect PIN State: If the entered PIN is incorrect, this state is activated. The user can try again or the card may be kept for security if attempts exceed a certain limit.
4. Card Security State: This state occurs when the card is kept for security due to multiple incorrect PIN entries or an invalid card.
5. Cancellation State: If the user cancels the operation, this state is activated and the card is returned.
6. Option Selection State: Once the PIN is correct, this state allows the user to choose from available options (withdrawing money, checking information, or making a transfer).
7. Request Processing State: After the user makes a choice, this state starts, and the system processes the selected request.
8. Final State: Not explicitly mentioned in the requirement, but it can be assumed that once the requested operation is completed or an error occurs, the ATM returns to the Arrival State, ready for the next user interaction.
