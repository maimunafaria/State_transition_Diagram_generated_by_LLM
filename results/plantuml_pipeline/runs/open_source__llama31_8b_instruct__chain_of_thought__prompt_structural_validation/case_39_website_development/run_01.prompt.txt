Website Development — Polished Requirement Specification

Functional Requirements

* Career Opportunities view (with updates or application form)

**Final states:**

* None explicitly mentioned, but it can be inferred that the system will remain in one of the above states until the user navigates away

**Events or conditions:**

* User selects a project
* User chooses to view photos or videos
* User selects career opportunities
* User chooses to view updates or open application form
* User submits job application

**Transitions:**

* From Homepage to Projects view (on selecting a project)
* From Projects view to Career Opportunities view (on selecting career opportunities)
* From Career Opportunities view to Updates view (on choosing to view updates)
* From Career Opportunities view to Application Form view (on choosing to open application form)
* From any state to Homepage (on user navigation)

**Missing or ambiguous details:**
