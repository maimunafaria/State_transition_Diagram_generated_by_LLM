Requirement:
Digital Watch — Polished Requirement Specification

Functional Requirements
1. The system shall allow the user to view and adjust the time.
2. The system shall enable the user to switch between changing hour, minutes, alarm hour, and alarm minutes by pressing a button.
3. The system shall allow the user to increase values while adjusting time settings.
4. The system shall provide an alarm feature that can be turned on or off by the user.
5. The system shall support when the set alarm time matches the current time, the system shall trigger the alarm to ring.
6. The system shall allow the user to stop the alarm by pressing a specific button.
7. The system shall have a light feature that turns on when the user presses a button and turns off when the button is released.

=== Chain-of-thought analysis response ===
### States:
- **Main State**: The primary state where time can be viewed and adjusted.
- **Alarm Off State**: The system is in this state when the alarm is turned off.
- **Alarm On State**: The system triggers an alarm sound when it transitions to this state.
- **Light On State**: The light feature is active, providing illumination.
- **Light Off State**: The light feature is inactive.

### Initial State:
- **Main State**: The watch starts in the main state with the alarm off and light off.

### Final States:
- **Alarm Off State**
- **Light Off State**

### Events or Conditions:
- **Mode Button Press**: Initiates a transition to different settings (hour, minute, alarm hour, alarm minute).
- **Increment Button Press**: Increases the current value being adjusted.
- **Alarm Stop Button Press**: Stops the alarm sound.
- **Time Match**: When the current time matches the set alarm time.

### Transitions:
1. **Main State**:
   - On **Mode Button Press**, cycle through settings (hour, minute, alarm hour, alarm minute).
   - On **Increment Button Press**, increase the value in the current setting; wrap around when reaching maximum (e.g., 59 minutes to 00 minutes).

2. **Alarm Off State**:
   - Monitors time continuously.
   - If **Time Match** occurs, transition to **Alarm On State**.

3. **Alarm On State**:
   - System rings alarm sound.
   - On **Alarm Stop
